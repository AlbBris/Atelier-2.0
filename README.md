# Atelier 2.0 — V1.7

Cette version ajoute un onglet **Atelier** avec un plan interactif permettant de positionner les zones, meubles, machines, stocks et outils.

## Fonctions du plan

- import d’une image ou d’un croquis du plan ;
- dimensions réelles facultatives ;
- création de repères liés aux champs `location` ;
- déplacement tactile des repères ;
- recherche d’un outil, d’une bobine, d’une machine ou d’une référence ;
- affichage du contenu d’un emplacement ;
- liste des emplacements encore non positionnés ;
- sauvegarde du plan avec la sauvegarde générale et l’export d’inventaire.
